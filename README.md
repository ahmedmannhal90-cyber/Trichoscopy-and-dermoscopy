# TrichoscaleDX — iPhone PWA Setup Guide

## What you need
- A computer (Mac or Windows)
- Node.js installed → https://nodejs.org (download the LTS version)
- A free Vercel account → https://vercel.com

---

## Step 1 — Set up the project

Open Terminal (Mac) or Command Prompt (Windows) and run:

```bash
# Install dependencies
cd TrichoscaleDX-PWA
npm install
```

---

## Step 2 — Generate app icons & splash screens

```bash
# Install Pillow (Python image library)
pip install Pillow

# Generate all icons and splash screens
python generate_assets.py
```

This creates:
- `public/icons/icon-192.png`
- `public/icons/icon-512.png`
- `public/icons/apple-touch-icon.png`
- `public/splash/splash-*.png` (6 iPhone sizes)

---

## Step 3 — Test locally on your iPhone

```bash
npm run dev -- --host
```

Look for a line like:
```
  ➜  Network: http://192.168.1.XX:5173/
```

On your iPhone (same WiFi), open **Safari** and go to that address.
You'll see the app running live.

---

## Step 4 — Deploy to Vercel (free hosting)

```bash
# Install Vercel CLI
npm install -g vercel

# Build the app
npm run build

# Deploy (follow the prompts — all defaults are fine)
vercel --prod
```

Vercel gives you a free URL like:
```
https://trichoscaledx.vercel.app
```

---

## Step 5 — Install on iPhone Home Screen

1. On your iPhone, open **Safari** (must be Safari, not Chrome)
2. Go to your Vercel URL
3. Tap the **Share** button (□ with ↑ arrow) at the bottom
4. Scroll down and tap **"Add to Home Screen"**
5. Name it **TrichoscaleDX** → tap **Add**

The app now appears on your home screen with the red TrichoscaleDX icon,
opens full-screen with no browser bar, and works like a native app.

---

## Updating the app

Any time you make changes:
```bash
npm run build
vercel --prod
```

The app updates automatically on all devices — no reinstall needed.

---

## File structure

```
TrichoscaleDX-PWA/
├── index.html              ← PWA meta tags, iPhone splash config
├── vite.config.js          ← Vite + PWA plugin config
├── package.json            ← Dependencies
├── generate_assets.py      ← Generates icons & splash screens
├── src/
│   ├── main.jsx            ← React entry point
│   └── App.jsx             ← TrichoscaleDX app (all logic + UI)
└── public/
    ├── icons/              ← Generated by generate_assets.py
    └── splash/             ← Generated by generate_assets.py
```
